## 一、产品概述

### 1.1 产品定位

河大家教是一款专注于**大学生家教撮合交易**的微信小程序平台。平台连接河南大学（及周边高校）的在校大学生教师与本地中小学家长，提供从教师发现、下单支付、试课确认到结算评价的完整交易闭环。

### 1.2 核心差异化模式

本平台有两大核心差异化设计：

| 差异化点 | 传统家教平台 | 河大家教 |
|----------|-------------|---------|
| **付费模式** | 家长直接付课时费给教师（平台难以抽佣） | **首课托管付费**：家长将首课费用支付到平台托管，试课满意后平台自动扣除佣金再结算给教师 |
| **联系方式获取** | 免费查看，跳单率极高 | **虚拟币信息费**：家长需消耗虚拟币查看教师电话/微信，按科目定价 5-25 元，杜绝零成本跳单 |

### 1.3 用户角色

| 角色 | 端 | 说明 |
|------|----|------|
| **家长** | 微信小程序（家长端） | 发布家教需求、浏览教师、下单支付、上课评价 |
| **教师** | 微信小程序（教师端） | 入驻申请、设置可授课时间、接单上课、提现收入 |
| **平台管理员** | Web管理后台 | 审核教师资质、管理订单、处理纠纷、财务对账、内容运营 |

## 二、全局通用设计

### 2.1 用户系统

**优先级：P0**

#### 功能概述
所有用户通过微信授权登录，绑定手机号后选择身份（家长/教师），完成账号体系初始化。

#### 用户故事
> 作为一个新用户，我希望能用微信一键登录，不需要额外注册账号，快速进入平台。

#### 交互流程

```
打开小程序 → 微信授权（获取openid+头像昵称）
   → 手机号授权绑定（微信getPhoneNumber）
   → 身份选择页：我是家长 / 我是教师
   → [家长] 直接进入首页
   → [教师] 引导进入入驻申请页
```

#### 数据字段

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | bigint | 主键 |
| openid | varchar(64) | 微信openid，唯一 |
| unionid | varchar(64) | 微信unionid（如开通开放平台） |
| nickname | varchar(64) | 微信昵称 |
| avatar_url | varchar(512) | 微信头像URL |
| phone | varchar(11) | 绑定手机号 |
| role | enum('parent','teacher','admin') | 用户角色 |
| status | tinyint | 1=正常 0=禁用 |
| created_at | datetime | 注册时间 |

#### 业务规则
- 一个 openid 只能绑定一个角色；角色一经选择不可自行修改（需联系客服）
- 手机号为必填项，用于防骚扰和联系凭证
- 头像昵称默认同步微信，支持后续自定义修改

家长可发布家教需求，填写科目、年级、地址、预算、期望时间等信息，平台将需求展示给匹配的教师（或教师可主动查看需求池）。

### 3.4 下单与首课托管支付

**优先级：P0（核心闭环）**

#### 功能概述
家长选定教师和时间后，通过微信支付将首课费用支付到平台托管账户。整个流程是平台商业模式的基石。

#### 用户故事
> 作为一个家长，我支付首课费用给平台后，如果试课不满意可以退款，满意了平台才把钱给老师——这样我比较放心。

#### 交互流程（详细）

```
① 教师详情页 → 点击"立即预约"
② 选择上课时间（从教师日历中选择可用时段）
③ 确认订单页：
   ┌────────────────────────┐
   │  订单确认              │
   │  教师：张三             │
   │  科目：初中数学         │
   │  时间：周六 09:00-11:00 │
   │  课时费：¥80/h × 2h    │
   │  ────────────────────  │
   │  首课托管金额：¥160.00 │
   │  （课后满意才结算给教师）│
   │  ────────────────────  │
   │  [确认支付 ¥160.00]    │
   └────────────────────────┘
④ 微信支付 → 支付成功
⑤ 钱进入平台托管账户（订单状态：待确认）
⑥ 教师收到接单通知，确认接单 → 状态变为：待试课
⑦ 试课完成后，家长在订单详情页操作：
   - [满意，确认完成] → 状态变为：待结算 → 平台自动扣佣金 → 结算给教师 → 已完成
   - [不满意，申请退款] → 进入纠纷处理流程（P1）
⑧ 家长确认后48小时未操作 → 自动确认完成（防止恶意不确认）
```

#### 数据字段（订单表）

| 字段 | 类型 | 说明 |
|------|------|------|
| order_id | bigint | 主键 |
| order_no | varchar(32) | 订单编号（唯一） |
| parent_id | bigint | 家长用户ID |
| teacher_id | bigint | 教师用户ID |
| subject | varchar(32) | 科目 |
| grade | varchar(32) | 年级 |
| lesson_date | date | 上课日期 |
| start_time | time | 开始时间 |
| end_time | time | 结束时间 |
| duration | decimal(4,1) | 课时长度（小时） |
| unit_price | decimal(10,2) | 单价（元/小时） |
| total_amount | decimal(10,2) | 总金额 |
| commission_rate | decimal(4,3) | 佣金比例（如0.15=15%） |
| commission_amount | decimal(10,2) | 佣金金额 |
| settlement_amount | decimal(10,2) | 教师结算金额 |
| status | enum | 见6.1状态机 |
| pay_transaction_id | varchar(64) | 微信支付流水号 |
| parent_confirm_time | datetime | 家长确认时间 |
| auto_confirm_deadline | datetime | 自动确认截止时间 |
| cancel_reason | text | 取消/退款原因 |

#### 业务规则
- 首课仅限首次课时托管，后续课时是否托管为 P2 需求
- 支付成功后不可直接取消（需联系客服走退款流程，P1）
- 教师拒绝接单 → 全额退款给家长
- 48小时自动确认机制：从教师标记"已上课"起计时


#### 数据字段

#### 业务规则

- 已消费的虚拟币不予退还（除非退款流程触发）

### 3.8 课后评价

**优先级：P1**

## 六、核心业务规则

### 6.1 订单状态机

```
                  ┌──────────┐
     家长支付成功  │  待确认   │ ← 等待教师接单
                  └────┬─────┘
                       │
          ┌────────────┼────────────┐
          │ 教师确认接单│            │ 教师拒绝/超时
          ▼            │            ▼
    ┌──────────┐       │      ┌──────────┐
    │  待试课   │       │      │  已取消   │ ← 自动退款
    └────┬─────┘       │      └──────────┘
         │              │
         │ 教师标记已上课│
         ▼              │
    ┌──────────┐        │
    │  进行中   │ ← 上课中│
    └────┬─────┘        │
         │              │
         │ 教师标记完成  │
         ▼              │
    ┌──────────┐        │
    │  待结算   │ ← 等待家长确认
    └────┬─────┘        │
         │              │
  ┌──────┼──────┐       │
  │家长确认│      │家长申请退款
  ▼      │      ▼       │
┌────┐   │  ┌──────┐    │
│已完成│   │  │纠纷中│──▶ 管理员仲裁
└────┘   │  └──┬───┘    │
         │     │        │
         │     ├──▶ 已完成（驳回退款）
         │     └──▶ 已取消（同意退款）
         │
         │ 超时48h自动确认
         ▼
       ┌────┐
       │已完成│
       └────┘
```

### 6.2 首课托管付费流程（详解）

```
Step 1: 家长下单支付
  - 家长选择教师和时间
  - 计算首课费用（单价 × 课时数）
  - 微信支付 → 资金进入微信支付商户号（平台账户）
  - 订单创建，status = "待确认"

Step 2: 教师响应
  - 教师收到通知，24h内确认接单 → status = "待试课"
  - 拒绝/超时 → status = "已取消" → 触发微信退款 → 原路退回

Step 3: 上课
  - 教师按时上课，课后在App标记"已上课"
  - status = "进行中"
  - 教师标记"完成" → status = "待结算"

Step 4: 家长确认
  - 家长在订单详情点击"满意，确认完成"
  - status = "待结算" → 系统自动结算：
    ① 扣除平台佣金（total_amount × commission_rate）
    ② 剩余金额计入教师余额
    ③ status = "已完成"
  - 家长48h未操作 → 自动确认完成

Step 5: 资金结算
  - 教师余额 = 累计已完成订单结算金额 - 已提现金额
  - 教师发起提现 → 管理员审核 → 企业付款到零钱
```

### 6.3 虚拟币计费规则

| 科目分类 | 单次查看费用 | 说明 |
|----------|-------------|------|
| 小学科目（语数英） | 5元（5币） | 需求量大，低价引流 |
| 初中科目（主科） | 10元（10币） | 核心市场 |
| 初中科目（副科） | 8元（8币） | |
| 高中科目（主科） | 15元（15币） | 客单价高 |
| 高中科目（副科） | 12元（12币） | |
| 竞赛/艺考辅导 | 25元（25币） | 高价值需求 |

业务规则：
- 查看同一教师联系方式7天内不重复收费
- 虚拟币充值后不可退款（除非平台停止运营）
- 虚拟币仅用于支付信息费，不属于金融产品

### 6.4 平台佣金规则

- 默认佣金率：**15%**（可从管理后台调整）
- 佣金 = 订单总额 × 佣金率
- 佣金在家长确认完成后自动扣除，无需教师额外操作
- 教师端看到的"预计收入" = 订单总额 × (1 - 佣金率)
- 退款订单不收取佣金
