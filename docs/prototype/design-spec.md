## 一、色彩系统

### 1.1 主色调

| 色值 | 名称 | 用途 |
|------|------|------|
| `#07C160` | Primary / 微信绿 | 主按钮、活动标签、选中态、品牌标识 |
| `#06AD56` | Primary Dark | 按钮按压态、深色渐变背景 |
| `#E8F8EF` | Primary Light | 浅色背景、选中标签底色、成功提示 |

### 1.2 辅助色

| `#1989FA` | Link Blue | 文字链、次要按钮、信息标签 |

| 色值 | 名称 | 用途 |

| `#FFF7EE` | Warning Light | 警告背景 |

### 1.4 中性色

| 色值 | 名称 | 用途 |

| `#1A1A1A` | Text Primary | 标题、重要文字 |

## 二、字体规范

### 2.1 字体族

```
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Helvetica Neue", "Microsoft YaHei", sans-serif;
```

PingFang SC 是 iOS 微信小程序默认中文字体，无需额外引入。

### 2.2 字号分级

| 级别 | 字号 | 行高 | 字重 | 使用场景 |
|------|------|------|------|----------|
| XXL | 20px | 28px | 700 | 页面大标题、余额数字 |
| XL | 18px | 26px | 600-700 | 卡片标题、教师姓名 |
| LG | 16px | 24px | 600 | 导航栏标题、金额数字 |
| MD | 14px | 22px | 400-600 | 正文、列表项、标签 |
| SM | 12px | 18px | 400 | 辅助说明、时间戳 |
| XS | 10px | 14px | 400 | Tab栏文字、角标 |

### 2.3 uView 对接

uView 提供 `size` 属性，直接使用预设：
- `size="xl"` (18px) — 标题
- `size="lg"` (16px) — 大号正文
- `size="md"` (14px) — 默认正文
- `size="sm"` (12px) — 辅助文字
- `size="xs"` (10px) — 极小文字

## 三、组件规范

### 3.1 按钮 (Button)

对接 uView UI：`<u-button>`

| 属性 | 主按钮 (Primary) | 次要按钮 (Outline) | 危险按钮 (Danger) | 文字按钮 |
|------|-----------------|-------------------|------------------|---------|
| 背景 | `#07C160` | 透明 | `#EE0A24` | 透明 |
| 文字色 | `#FFF` | `#07C160` | `#FFF` | `#1989FA` |
| 边框 | 无 | `1px solid #07C160` | 无 | 无 |
| 圆角 | 8px | 8px | 8px | — |
| 高度 | 44px | 44px | 44px | — |
| 字号 | 16px | 16px | 16px | 14px |
| 按压态 | `#06AD56` | `#E8F8EF` | `#D00820` | 透明度 0.7 |

**尺寸变体**：
- **大按钮**：width 100%，height 48px，用于支付/提交等主要操作
- **默认按钮**：height 44px，padding 10px 24px
- **小按钮**：height 32px，padding 6px 14px，font-size 12px，用于卡片内操作

**uView 对应**：
```html
<!-- 主按钮 -->
<u-button type="primary" shape="circle" size="default">立即预约</u-button>
<!-- 次要按钮 -->
<u-button type="primary" plain shape="circle">收藏</u-button>
<!-- 小按钮 -->
<u-button type="primary" size="mini" shape="circle">确认</u-button>
```

### 3.2 卡片 (Card)

| 属性 | 值 |
|------|-----|
| 背景 | `#FFFFFF` |
| 圆角 | `12px` |
| 阴影 | `0 2px 12px rgba(0,0,0,0.08)` |
| 内边距 | `14px-16px` |
| 间距（卡片间） | `10px-12px` |

**教师卡片**（首页列表）：
- 头像：56×56px，圆形
- 卡片内布局：flex row，头像 + 信息区
- 信息区：姓名/评分行 → 学校信息行 → 标签行 → 价格行

**订单卡片**：
- 头部：订单号 + 状态标签，space-between
- 主体：教师头像(44px) + 信息
- 底部：金额 + 操作按钮组

### 3.3 输入框 (Input)

对接 uView UI：`<u-input>`

| 属性 | 值 |
|------|-----|
| 高度 | 44px |
| 圆角 | 8px |
| 边框 | `1px solid #EBEDF0` |
| 聚焦边框 | `1px solid #07C160` |
| 字号 | 14px |
| 内边距 | 10px 12px |
| 占位符颜色 | `#999999` |

**搜索栏变体**：
- 背景 `#FFFFFF`，圆角 8px
- 内嵌搜索图标 + 输入框
- 外阴影 `0 1px 3px rgba(0,0,0,0.06)`

### 3.4 标签 (Tag)

对接 uView UI：`<u-tag>`

| 类型 | 背景色 | 文字色 | 用途 |
|------|--------|--------|------|
| green | `#E8F8EF` | `#07C160` | 已通过、可预约、成功状态 |
| blue | `#EEF4FF` | `#1989FA` | 信息标签、科目标签、订单状态 |
| red | `#FFF0F0` | `#EE0A24` | 已驳回、已取消、已预约 |
| yellow | `#FFF7EE` | `#FF976A` | 待审核、待确认 |
| gray | `#F5F5F5` | `#999999` | 默认/禁用 |

**圆角**：普通标签 4px，胶囊标签 16-20px（用于筛选、时间选择）

**尺寸**：
- 小标签：padding 2px 8px，font-size 10px
- 默认标签：padding 4px 10px，font-size 12px

### 3.5 弹窗 (Modal / Popup)

对接 uView UI：`<u-modal>` / `<u-popup>`

- **确认弹窗**（如"消耗X币查看联系方式"）：
  - 标题 + 说明文字 + 取消/确认双按钮
  - 确认按钮使用主色 `#07C160`
- **底部弹出**（如筛选面板）：
  - 从底部滑入，圆角顶部 16px
  - 最大高度 60vh

### 3.6 导航栏 (NavBar)

对接 uView UI：`<u-navbar>`

- 高度：44px
- 背景：`#FFFFFF`
- 标题居中，字号 16px，字重 700
- 左侧返回箭头 + 右侧可配置图标/文字
- 底部 1px 浅色分割线

### 3.7 Tab栏 (TabBar / Tabs)

**底部Tab栏**（对接 uView：`<u-tabbar>`）：
- 高度：56px（含 safe-area）
- 背景：`#FFFFFF`
- 选中态：图标+文字变绿 `#07C160`
- 未选中：`#999999`
- 图标尺寸：20px
- 文字：10px

**顶部Tab切换**（对接 uView：`<u-tabs>`）：
- 背景：`#FFFFFF`
- 激活态：底部 2px `#07C160` 指示条 + 文字加粗
- 文字：12-14px
- 可横向滚动

### 3.8 搜索栏与筛选

对接 uView UI：`<u-search>` + `<u-dropdown>`

**搜索栏**：
- 圆角 8px，背景白色
- 搜索图标 + placeholder "搜索教师/科目"
- 可选右侧筛选按钮

**筛选栏**：
- uView Dropdown 组件
- 下拉面板展示筛选项
- 筛选标签使用胶囊样式

### 3.9 列表项 (Cell)

对接 uView UI：`<u-cell>` / `<u-cell-group>`

用于个人中心菜单、设置页等场景：
- 左侧图标(20px) + 标题(14px) + 右侧箭头
- 高度 48px
- 底部 1px 分割线

## 五、间距系统

### 5.1 基础间距

基于 4px 网格系统：

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 4px | 紧密元素间距、标签内边距 |
| sm | 8px | 图标与文字间距、标签间距 |
| md | 12px | 卡片内边距、列表项间距、组件间间距 |
| lg | 16px | 卡片 padding、区块间距 |
| xl | 20px | 大区块间距、详情页头部 padding |
| xxl | 24px | 页面级间距、余额卡片 padding |

### 5.2 页面布局

```
┌─────────────────────────────────┐
│  Status Bar (44px)              │  ← 系统状态栏
├─────────────────────────────────┤
│  NavBar (44px)                  │  ← 导航栏
├─────────────────────────────────┤
│  Page Content                   │
│  ┌─ padding: 12px ───────────┐ │
│  │  Search Bar (44px)        │ │
│  │  margin-bottom: 10px      │ │
│  │  Filter Row               │ │
│  │  margin-bottom: 12px      │ │
│  │                           │ │
│  │  Card (padding: 14px)     │ │
│  │  margin-bottom: 12px      │ │
│  │  Card ...                 │ │
│  └───────────────────────────┘ │
├─────────────────────────────────┤
│  TabBar (56px)                  │  ← 底部Tab栏
│  Safe Area (env)                │
└─────────────────────────────────┘
```

### 5.3 安全区域

- 顶部安全区：`env(safe-area-inset-top)`，约 20-44px（iPhone X 以上）
- 底部安全区：`env(safe-area-inset-bottom)`，约 0-34px
- 使用 uView 的 `custom-style` 或组件的 `safeAreaInsetBottom` 属性自动处理

## 六、页面流转关系

### 6.1 家长端核心路径

```
首页（搜索/浏览教师）
  ├─→ 教师详情页
  │     ├─→ 立即预约 → 下单支付页 → 微信支付 → 订单列表
  │     ├─→ 收藏教师
  │     └─→ 联系教师（消耗虚拟币）
  ├─→ 订单Tab → 订单列表页 → 订单详情
  ├─→ 消息Tab → 聊天列表页 → 聊天详情
  └─→ 我的Tab → 个人中心
        ├─→ 虚拟币钱包 → 充值/消费记录
        └─→ 我的收藏
```

### 6.2 教师端核心路径

```
入驻申请页 → 提交审核 → 等待审核
审核通过后：
  教师首页
    ├─→ 家教日历 → 设置可授课时间
    ├─→ 订单管理 → 确认接单/拒绝 → 标记上课 → 标记完成
    ├─→ 收入管理 → 查看收入 → 提现
    └─→ 评价查看
```

### 6.3 管理后台路径

```
登录 → 数据看板
  ├─→ 教师审核 → 审核详情 → 通过/驳回
  ├─→ 订单管理 → 订单详情 → 退款处理
  ├─→ 用户管理
  └─→ 财务管理
```

## 八、设计检查清单

- [x] 色彩统一使用 Design Token，避免硬编码色值
- [x] 所有可点击区域 ≥ 44×44px（符合微信小程序最小点击区域）
- [x] 文字与背景对比度 ≥ 4.5:1（无障碍标准）
- [x] 底部固定按钮留出 safe-area 空间
- [x] 加载态、空态、错误态需有对应设计（MVP可简化）
- [x] 按钮/标签命名保持一致（全部/待确认/进行中/已完成）
- [x] 金额颜色统一使用 `#EE0A24`（支出）或 `#07C160`（收入）
